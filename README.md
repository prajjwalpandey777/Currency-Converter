# Currency Converter 💱

A modern and responsive **Currency Converter Web App** built using **HTML, CSS, and JavaScript**.
This project allows users to convert currencies in real-time using live exchange rates with country flags support.

---

## 🚀 Features

* 🌍 Convert between multiple international currencies
* 📡 Real-time exchange rates using API
* 🏳️ Dynamic country flags
* 🎨 Modern neon UI design
* 📱 Fully responsive for mobile, tablet, and desktop
* ⚡ Fast and lightweight

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
* **Exchange Rate API**
* **Flags API**
* **Font Awesome Icons**

## ⚙️ How It Works

1. User enters an amount
2. Selects source currency
3. Selects target currency
4. Clicks on **Get Exchange Rate**
5. App fetches live exchange rates and displays converted value

---

## 🔗 APIs Used

### Exchange Rate API

```bash
https://open.er-api.com/v6/latest
```

### Flags API

```bash
https://flagsapi.com/
```

---

## 🧠 Main Functionalities

### Dynamic Currency Dropdowns

All currencies are loaded dynamically using JavaScript.

### Live Exchange Conversion

Fetch API is used to get real-time currency rates.

### Dynamic Flag Updates

Country flags automatically change when currency changes.
